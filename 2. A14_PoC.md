# Operational Guide: Identity Decoupling

**Target Component:** DICE Hardware Logic / ARMv8-A TrustZone

**Exploit Primitive:** Asynchronous DMA Injection & L1 Instruction Cache Poisoning

**Pre-requisite:** Baseband (CP) DMA Bus-Master Access

---

### I. Step-by-Step Weaponization Sequence

#### 1. The Race for Early DMA (CWE-1190)

The exploit window opens during the pre-iBoot phase. The attacker utilizes a buffer overflow in the Baseband’s PCIe driver to gain uncontrolled **DMA Bus-Master** privileges.

* **The Operation:** While the Secure Boot chain is loading the Platform Identity Subsystem, the Baseband writes a "Shadow Page" to physical address range `0x8XXXXXXX`.
* **The Goal:** To position malicious code in a memory region that will be executed, while keeping legitimate code in a region that will be measured.

#### 2. Triggering the DICE Shimming (CWE-1283)

The attacker must now trick the DICE hardware engine.

* **The Operation:** The exploit triggers a **Memory-Mapped I/O (MMIO)** rebind. It directs the DICE engine's pointers to the "Shadow Page".
* **The Decoupling:** Simultaneously, the attacker uses the DMA primitive to poison the **L1 Instruction Cache** of the Application Processor (AP) with a malicious payload.
* **The Result:** The DICE engine hashes the clean shadow page and generates a legitimate **CDI (Compound Device Identifier)**. The AP begins executing the poisoned cache entries, establishing initial control.

#### 3. Persistence Pivot: DART Bypass & Identity Exfiltration
Once the system is booted, the exploit pivots to a hardware-level bypass of the **IOMMU (DART)**.

* **The Pivot Point:** Offset **0x1237** within the DART translation tables is weaponized. This address resides in the peripheral-to-kernel communication map, serving as the bridge for the **secondary siphon**.
* **Validation Bypass:** By forcing non-standard handshakes at `0x1237`, the exploit bypasses `IOMFBServer` validation. This facilitates the extraction of the hardware-verified **10,290-byte AP Ticket**, enabling cloud-level identity portability.
* **Kernel Access:** This allows the Bluetooth/Baseband peripheral to target restricted kernel space directly, bypassing the DART sandbox.

#### 4. Stealth Execution: TRNG Entropy Failure (CWE-331)
To ensure the exfiltration initiated in Section 3 remains undetected, the exploit manipulates the **AppleTRNG** during the setup of the `0x1237` channel.

* **Synchronized Seeding:** During the initialization of the `0x1237` DMA channel, the Secure Enclave's entropy source is forced to return repetitive seeds (*0x00* or *0xFF*).
* **Fixed-Seed Encryption:** By using these predictable seeds, the exfiltrated **AP Ticket** and **WombatStream** telemetry are encrypted as "fixed noise." This ensures that the data moving across the `0x1237` bridge is indistinguishable from standard system telemetry to forensic mirrors.

---

### II. Data Exfiltration: The WombatStream & "Package"

The "Package" (the exfiltrated data) is staged and moved via the following sub-processes:

1. **Payload Identification**: A 173-byte hex payload is staged in the **I/O High Buffer** (the boundary between the Secure Enclave and the AOP).
2. **Authorization Bypass:** This payload resides in a synchronous TCCD request buffer but lacks `kTCCServiceBluetoothAlways` headers, indicating it has "staged" without triggering system monitoring.
3. **Telemetry Mirroring:** The `App.Intents.Transcript` (correlated with **WombatStream**) mirrors speech recognition and location data.
4. **Dual-Layer Egress:** While `com.apple.aonsensed` satisfies local integrity checks, the **Secondary Siphon** exfiltrates the same payload to the Icelandic C2 node (`kaylees.site`) via the `0x1237` DART bypass.

---

### III. Why Hardware Protections Fail
* **AMFI & PPL:** These software-defined guards are bypassed because the initial DICE-SHIM occurs before they are initialized.
* **DART (IOMMU):** The hardware memory isolation fails because the **0x1237** pivot point lacks proper atomicity in translation table updates, allowing peripheral access to restricted kernel memory.
* **Secure Enclave (SEP):** The predictability of the TRNG seeds during `0x1237` setup compromises the cryptographic integrity of the entire data stream.

---

**Conclusion:** The A14 compromise is a dual-layered failure. The **DICE-SHIM** achieves initial invisible entry, while the **DART Bypass at 0x1237** ensures persistent, masked exfiltration. By weaponizing the lack of isolation between peripheral DMA and kernel memory, the attacker maintains a "Secondary Siphon" that is entirely transparent to the host operating system
